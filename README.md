# Spot the Scam

เว็บเกมฝึกแยกข้อความหลอกลวง สำหรับนักศึกษา

## ไฟล์
- `index.html` โครงหน้าเว็บ
- `style.css` สไตล์และธีมสว่าง/มืด
- `questions.js` ข้อสอบ 10 ข้อ (แก้หรือเพิ่มข้อได้)
- `script.js` ตรรกะเกมและหน้าสรุปผล

## วิธีใช้
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## วิธีเผยแพร่
ลากโฟลเดอร์นี้ไปวางที่ app.netlify.com/drop หรืออัปโหลดขึ้น GitHub Pages / Vercel

## หมายเหตุ
ถ้าเพิ่มหรือลดจำนวนข้อ ให้แก้ข้อความ "10" ใน `index.html` (หน้าแนะนำ) และ `script.js` (คำว่า /10 และ "ถูก ... ข้อ") ให้ตรงกัน
